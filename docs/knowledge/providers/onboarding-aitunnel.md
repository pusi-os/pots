# AITUNNEL — как начать (онбординг)

Сервис в приложении: **AITUNNEL** (`aitunnel`).

## 1. Регистрация

1. Откройте панель: **https://aitunnel.ru/panel/login** → «Регистрация» (вход в панель — https://aitunnel.ru/panel).
2. Подтвердите e-mail — после этого можно создать ключ и пополнить баланс.

## 2. API-ключ

1. Раздел ключей: **https://aitunnel.ru/panel/keys**.
2. Нажмите «Новый» → задайте имя; при желании сразу настройте **бюджет**, разрешённые модели, IP, срок.
3. «Создать ключ» → откроется ключ формата `sk-aitunnel-…` вместе с готовым примером запроса. Ключ можно снова показать в панели.
4. «Проверить ключ» делает **бесплатный** запрос `GET /aitunnel/key`.
5. Вставьте ключ в Pots: Настройки → Сервисы → AITUNNEL → «API-ключ».

Особенность: число ключей зависит от баланса — при 0 ₽ создать ключ нельзя, первый ключ доступен с любым положительным балансом, дальше каждый полный 1 000 ₽ даёт ещё один. Уже созданные ключи при падении баланса продолжают работать.

## 3. Пополнение баланса

Страница пополнения: **https://aitunnel.ru/panel/purchase**. Модель pay-as-you-go, без подписок.

| Способ | Минимум | Детали |
|---|---|---|
| Карта или СБП | **от 500 ₽** | мгновенное зачисление, карту можно сохранить |
| Счёт для компаний | **от 10 000 ₽** | баланс пополняется автоматически после оплаты, УПД через ЭДО |
| Криптовалюта (NOWPayments) | **от 1 500 ₽** | к сумме начисляется бонус **+20 %** |

Есть авто-пополнение с сохранённой карты (порог / сумма / месячный лимит) и возврат неиспользованных средств в течение **24 часов** после пополнения картой, СБП или по счёту (крипта не возвращается). Промокоды активируются на https://aitunnel.ru/panel/bonuses/promo.

## 4. Что подставить в приложении

- Base URL: `https://api.aitunnel.ru/v1` (зеркало при блокировке основного хоста: `https://ru-api.aitunnel.ru/v1`).
- Заголовок: `Authorization: Bearer sk-aitunnel-…` (или `x-api-key`).
- Баланс: `GET https://api.aitunnel.ru/v1/aitunnel/balance` → `balance` (₽), опционально `budget`.
