# PlusVibeAPI — как начать (онбординг)

Сервис в приложении: **PlusVibeAPI** (`plusvibe`), резервный хост — **PlusVibeAPI (резерв)** (`plusvibe-reserve`).
Ключ, баланс и каталог у основного и резервного адреса общие.

## 1. Регистрация

1. Откройте **https://plusvibeapi.ru/register** (на лендинге — кнопка «Получить ключ»).
2. Подтвердите e-mail — после подтверждения новому аккаунту начисляется **стартовый бонус 100 ₽ на 30 дней** (один раз, по условиям акции).
3. VPN и зарубежная карта не нужны: сервис работает с российского эндпоинта.

## 2. API-ключ

1. Войдите в личный кабинет: **https://plusvibeapi.ru/login**.
2. Раздел ключей: **https://plusvibeapi.ru/dashboard/keys** → «Создать ключ».
3. Ключ начинается с `sk-pv-…` и **показывается один раз** — сохраните его сразу.
4. Вставьте ключ в Pots: Настройки → Сервисы → PlusVibeAPI → «API-ключ».

Проверка, что ключ живой: `GET https://plusvibeapi.ru/v1/balance` с заголовком
`Authorization: Bearer sk-pv-…` → `{"balance_rub": <число>, "currency": "RUB"}`.

## 3. Пополнение баланса

Раздел: **https://plusvibeapi.ru/dashboard/billing**. Модель — предоплата, списание по факту.

| Кто | Как платить | Детали |
|---|---|---|
| Физлицо | Карта РФ | Пополнение **от 100 ₽**, подписки и абонплаты нет |
| Юрлицо / ИП | Счёт, безнал | Договор, акты, закрывающие документы; ЭДО (Диадок/СБИС) — по запросу; оператор — ИП на УСН, **без НДС** |
| Проверенные организации | Постоплата по договору | Начинается с предоплаты, лимит согласуется по договору |

Ошибки провайдеров (5xx) не тарифицируются. При нулевом балансе платные методы отвечают `402`.

## 4. Что подставить в приложении

- Base URL: `https://plusvibeapi.ru/v1` (резерв: `https://gw.plusvibeapi.ru/v1`).
- Заголовок: `Authorization: Bearer sk-pv-…` (для Anthropic-клиентов — `x-api-key`).

## Проверено / не проверено

Проверено 2026-11-23: страницы `/register`, `/dashboard/keys`, `/dashboard/billing` отвечают (307 на `/login` — путь кабинета есть), `/v1/models` без ключа → 401. Способы оплаты и бонус — с лендинга и FAQ (официальный сайт). Сумму минимального первого пополнения и скорость зачисления картой провайдер на сайте не указывает — в онбординге не обещаем.
