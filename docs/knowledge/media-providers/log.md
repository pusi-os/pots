# Media provider log

- **2026-11-10** — bundle created; PlusVibeAPI contract snapshot from official docs (`/docs/api-reference`, `/docs/images-generations`, `/docs/video-generations`, `/docs/media-generation`, `/docs/media-pipeline`, `/docs/media-models`, `/docs/media-webhooks`) + live `/api/media-catalog` shape. Runtime adapter lands in Phase 1 of the media-studio plan.
- **2026-11-12** — Pots fixes: `PlusVibeMediaProvider` now sends the body as a string (a bare `JsonObject` failed without `ContentNegotiation`), uses `HttpTimeout` (180 s request/socket, 30 s connect), reuses the same `Idempotency-Key` and quote on retries, and sends `mode = image-to-image` with references. Contract notes (reconcile on `submitting`, `mode`, cheap test model `gpt-image-2`) added to `plusvibe.md`. The `mode` value is not yet verified against the live API.
- **2026-11-17** — `mode` разобран как per-model маршрут: снимок живого `/api/media-catalog` (214 моделей, `mode` у 38, у 22 из них нет `image-to-image`) показал, что константа `image-to-image` даёт 422 у половины моделей (`nano-banana`/`nano-banana-pro` — `[text-to-image, edit]`). Pots теперь берёт только значение, объявленное моделью и принадлежащее её семейству, и не отправляет `mode` вовсе, когда маршрута своего семейства нет (default провайдера); UI говорит об этом под полосой референсов. Снимок каталога лежит в `docs/design/media-expansion/pots-media-catalog-live-2026-11-17.json`, тотальный тест — `MediaReferenceModeFixtureTest`. Живой generate по-прежнему не проверялся (платно, проверяет владелец).
- **2026-11-17** — `edit` добавлен как image-маршрут по решению владельца: значение считается маршрутом image-семейства, только если модель его объявляет И каталог документирует `edit` с обязательным image-входом (`requiredInputs.operations[]`: `when.mode="edit"`, `anyOf` с `opts.image_url`/`opts.image_file_id`/`opts.image_base64`). Квалифицируются `nano-banana`, `nano-banana-pro`, `ideogram-v3`, `ideogram-character` (у них референс теперь идёт через `mode=edit`, UI-строка про «не умеет референс» у них пропала); `recraft` и `grok-imagine-2.0-ext` по-прежнему уходят без `mode`. Глобального синонима нет: `wan-2-7` объявляет `edit` с video-входом и продолжает получать `image-to-video` (закреплено тестом). Парсинг `requiredInputs` — только через `as?`: дрейф формы деградирует в «alias не применён», не в крэш. Приёмка — по фикстуре и прайс-таблицам каталога, живых генераций не запускалось.
- **2026-11-22** — добавлены два медиа-контракта: `polza.md` и `aitunnel.md` (карта `t_4c0ae3be`, только чтение и `curl`, платных генераций не было). AITUNNEL: публичные каталоги `/public/aitunnel/models/{images,videos}` (50 и 35 моделей) без ключа, картинки синхронно `/v1/images/generations` (до 9 мин, ответ `b64_json`, без URL), видео `POST /v1/videos` (202) → `GET /v1/videos/{id}` → `/v1/videos/{id}/content` (нужен `Authorization` или `?token=`), цена — серверный резерв worst-case + `size_prices` ₽/с, ключа идемпотентности нет. Обе таблицы «метод `MediaProvider` → чем закрывается → чего нет» и разделы «минимальный путь» — в документах. Живые генерации не проверялись (нет ключей).
- **2026-11-23** — добавлены ещё два медиа-контракта: `gptunnel.md` и `llm-router.md` (карта `t_19d5c123`; только чтение доков и `curl` без ключа, платных генераций не было). GPTunnel: CreativeLab API v2, база `https://gptunnel.ru/api/v2/media`, авторизация `Authorization` с `Bearer` или без; каталог `GET /models` (`?type=IMAGE|VIDEO|AUDIO`) отдаёт `params`/`inputs`/`price`+`price_unit`/`price_input`/`discount_percent`/`deprecated*`, но **требует ключа** (живой `401`, публичным не является); `POST /price` — точная котировка той же функцией, что и списание, без запуска (`currency: "RUB"`); `POST /tasks` — единая точка с `idempotency_key` (повтор = та же задача, другое тело = `409`/`code 23`), `webhook_url` (HMAC-SHA256 с API-ключом как секретом, ретраи 5/20/60/180 с) и `wait` ~30 с; `GET /tasks/:id` — `queued|running|done|failed`, `result[].url`, `price`, `error{code,title,message}`, `refunded`; ссылки на результат живут 48 ч; в объекте задачи валюты полем нет — `currency: "RUB"` приходит только в ответе `/price` (расхождение со спецификацией карты зафиксировано в документе). LLM Router: база `https://llm-router.org`, `Authorization: Bearer` (для Anthropic-входа `x-api-key`); только картинки и только синхронно — `POST /v1/images/generations` (`model`, `prompt`, `n`, `size`, `aspect_ratio`, `quality`, `response_format: url|b64_json`) и `POST /v1/images/edits` (multipart `image`+`mask` только у `gpt-image-*`, либо JSON `images:[{url}]` для композиции); ответ — `{created, data:[{b64_json}]}` без `usage`/цены; `Idempotency-Key` поддерживается заголовком; `GET` на оба пути → `405` («Supported methods: POST»), задач и поллинга нет; каталог `GET /v1/models`, `GET /v1/pricing` и `GET /v1/balance` существуют, но требуют ключа и не документированы (форма прайса известна только из нашего DTO). Обе таблицы «метод `MediaProvider` → чем закрывается → чего нет» — в документах; живые генерации не запускались.
