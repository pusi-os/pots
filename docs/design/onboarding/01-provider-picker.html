Онбординг: выбор провайдера

Первый шаг онбординга: список полнофункциональных медиа-провайдеров. PlusVibe выбран по умолчанию (бесплатный ключ приложения встроен, пользователь может ввести свой); остальные — контурные карточки-кнопки. Под списком — свёрнутая секция «Как зарегистрироваться и получить ключ» (раскрытое состояние — в 02-key-guide.html).

01

Список провайдеров, секция закрыта

Состояние по умолчанию: провайдер предвыбран, инструкция свёрнута. Подпись «по умолчанию» объясняет, почему PlusVibe уже активен. Секция «Как получить ключ» видна всегда — она и есть следующий шаг онбординга.
