Онбординг: как получить ключ

Второй шаг: под выбранным провайдером раскрыта секция-аккордеон — шаги 1-2-3, плейсхолдер кнопки «Видео-инструкция» и поле API-ключа с кнопкой «Проверить и добавить». Тексты шагов — из docs/knowledge/providers/onboarding-plusvibe.md (карта t_cd33ff78); для остальных провайдеров своя тройка шагов из соседних файлов, вёрстка одна.

360 dp · 1 px = 1 dp тексты — onboarding-*.md видео — плейсхолдер, тач-таргет 44 dp inline SVG · currentColor
01

Секция раскрыта

Секция открывается под списком провайдеров и двигает контент вниз (итоговое состояние — цель, высота анимации не нормируется). Шаги читаются сверху вниз, кнопка видео отделяет «инструкцию» от «действия», поле ключа — финал экрана.

02

320 и 300 dp: раскрытая секция

Шаги переносятся на две строки без потери сетки: номер-круг фиксирован слева, текст занимает остальное. Поле и кнопка растягиваются на всю ширину — им теснее всего на 300 dp, но и там сохраняются 44 dp высоты.

03

Откуда шаги у каждого провайдера

Тексты шагов — из docs/knowledge/providers/onboarding-*.md (карта t_cd33ff78). Вёрстка одна, меняется только содержимое трёх строк: при переключении провайдера шаги перечитываются из его файла.

Шаг — одна строка описания, не абзац. В карточку шага попадает суть (адрес, путь в кабинете, минимум), а не таблица способов оплаты: детали остаются в onboarding-*.md. Длинные описания шага переносятся на вторую строку — сетка от этого не ломается (номер-круг фиксирован слева).
Один провайдер — один набор шагов. Шаги зависят от выбранного провайдера и меняются при переключении карточки: аккордеон закрывается, поле ключа очищается (см. 03-key-states.html — после смены провайдера состояние «введён» сбрасывается).
