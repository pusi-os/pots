Шапки секций настроек: белый цвет и иконка

Баг подтверждён в ui/settings/MediaModelsSettings.kt:100: Text(title, style = labelLarge) без указания цвета. labelLarge не задаёт цвет, поэтому текст наследует цвет контента по умолчанию — чёрный. На тёмном фоне #121212 заголовок «Изображения» практически исчезает: контраст 1.12 : 1 при норме 4.5 : 1.

360 dp · 1 px = 1 dp color = onSurface #FFFFFF titleSmall 14/20 · 600 иконка 18 dp слева
01

Было → стало

Один и тот же экран настроек медиа-моделей. Слева — текущий рендер: три секции есть, но их заголовки не видны. Справа — предлагаемый: цвет onSurface, иконка в начале, счётчик моделей справа.

02

Почему баг виден только в тёмной теме

В светлой теме тот же код выглядел нормально: чёрный текст на почти белом фоне читался сам собой, поэтому отсутствие цвета не бросалось в глаза. Это не «сломалось при переходе на тёмную тему» — цвет просто никогда не задавался.

03

Анатомия шапки

Увеличение 2×. Заголовок всегда одна строка с ellipsis, поэтому иконка центрируется по вертикали (CenterVertically) — на короткой строке это совпадает с базовой линией текста и не «висит» при длинном названии секции.

Что менять в коде

MediaModelsSettings.kt:78-95 ModelPicker(title = "Изображения") / "Видео" добавить параметр иконки; для «Аудио» — новая секция с MediaKind.Audio
Строки секций только title Res.string.media_section_images / _video / _audio вместо литералов
Иконки — Material, не PotsIcons. ui/icons/PotsIcons.kt содержит клубные иконки (ClubKey, ClubCloud, LocalModel, PotsGame) — к медиа-секциям они не относятся. Для секций берём Icons.Outlined.Image, Icons.Outlined.Movie, Icons.Outlined.GraphicEq — тот же набор, что уже используется в настройках.
Иконка — декоративная. У Icon должен быть contentDescription = null: заголовок рядом уже называет секцию, дублирование в TalkBack мешает. Счётчик, наоборот, озвучивается: «Изображения, 12 моделей».
Счётчик не обязателен. Если число моделей в секции неизвестно (каталог ещё грузится), счётчик не показываем — заголовок не должен прыгать. Место под него не резервируем: он правый и уходит вместе с текстом; при появлении заголовок получает на ~24 dp меньше, а названия секций короткие — обрезки не случается.
