Ряд сортировки: шесть кнопок-иконок в одну строку

Сейчас это шесть FilterChip с текстовыми подписями в Row без горизонтального скролла: на 360 dp им нужно ~542 dp при доступных 344 — они не помещаются и расползаются. Решение: только иконки, 44 × 44 dp каждая, подпись по долгому нажатию.

360 dp · 1 px = 1 dp 6 × 46 + 6 × 8 + 1 = 325 ≤ 344 touch target 44 × 44 подписи — по long-press

Направление по умолчанию. Для «Цены» первое нажатие — по возрастанию (дешёвые сверху), для остальных — по убыванию. Это то, что делает comparator в ModelSortOption; иконка каретки просто показывает фактическое направление, а не зашитое «вниз».
«Рекомендуемые» без направления. Составной ключ (дата + Elo) не имеет осмысленного обратного порядка, поэтому каретка у неё не показывается: только активная заливка.
Доступность. У каждой кнопки обязателен contentDescription с подписью и направлением — иконка без текста иначе нема для TalkBack. Активная кнопка помечается Modifier.semantics { selected = true }; фильтр — toggleable, а не selectable.
