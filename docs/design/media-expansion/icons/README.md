# Иконки расширения медиа-студии POTS

Комплект к спеке `/home/al/wiki/design/pots-media-ux-spec.md` (карточка `t_5b9da93f`, доска `pots`, автор @joni).

Формат: 24×24 `viewBox`, один цвет `fill="currentColor"` — в приложении тинтуется через `MaterialTheme.colorScheme.*`, как существующие `Icons.Filled.*`. Стиль — Material Filled: те же оптические веса, что у иконок `MediaStudioTopBar.kt` / `MediaDock.kt` / `MediaCanvas.kt`.

Импорт в Compose: конвертация в `ImageVector` материал-пайплайном проекта; фолбэк — `painterResource` с тинтом.
