## 0. Принципы и отправные точки

Текущий стиль (не менять, только наследовать):

- Стеклянные капсулы: `Surface(alpha ≈ 0.9, tonalElevation)`, скругления 22/20/16/14/12/11 `.dp`.
- Чипы тулбара: `RoundedCornerShape(12.dp)`, `labelMedium`, паддинг `10.dp × 6.dp`, фон `tertiaryContainer`.
- Сегмент режимов: капсула `14.dp`, кнопки со скруглением `11.dp`, иконка `18.dp` в паддинге `7.dp`; активная — `primaryContainer`, неактивная — прозрачная, `onSurfaceVariant`.
- Элемент канваса: 232 `.dp` (`CANVAS_ELEMENT_SIZE_DP`), скругление `12.dp`, выделение — кольцо `2.dp primary`; панель операций — капсула у нижнего края.
- Интерактив: `handCursor()` на всём кликабельном; `contentDescription` на русском у каждой иконки.

Правила дизайна:

1. Дизайн — как вещь работает: каждая операция видна только тогда, когда нужен её объект (контекстные панели — паттерн CapCut).
2. Простота: одна главная дорожка таймлайна + аудиодорожка в v1; мультитрек — позже.
3. Ничего не терять: промпт, параметры и референсы не очищаются ни при смене режима, ни при ошибке.
4. Среда — десктоп (Omarchy/Hyprland): ховер-состояния, клавиатура, точность мыши; тач-жесты остаются вторичными (приложение KMP).
5. Все подписи — на русском.

## 1. Третья кнопка «Аудио» в тулбаре режимов

- `ModeSegment` становится трёхкнопочным: **Изображение** (`Icons.Filled.Image`), **Видео** (`Icons.Filled.Movie`), **Аудио** (`mode-audio.svg` — музыкальная нота, без подписи).
- Геометрия новой кнопки — ровно как у существующих: иконка `18.dp`, паддинг `7.dp`, активная = `primaryContainer`/`onPrimaryContainer`, неактивная = прозрачная/`onSurfaceVariant`. Третья кнопка не меняет ширину капсулы — только добавляет сегмент.
- `contentDescription = "Режим аудио"`.
- Состояние `isVideoMode: Boolean` заменить на `enum MediaMode { IMAGE, VIDEO, AUDIO }`; переключение — клик по неактивному сегменту (как сейчас).
- При переключении меняется: набор чипов (§2), плейсхолдер дока — **«Опиши звук или речь…»** (для музыки — «Опиши трек: жанр, настроение…»), фильтр шита моделей (`kind=audio|music`), поведение канваса (§3).
- Черновик промпта хранить отдельно на каждый режим: переключение режимов текст не стирает.

## 2. Чипы параметров аудио (вместо разрешения/соотношения сторон)

В режиме аудио чипы разрешения и соотношения сторон скрываются; вместо них — чипы, построенные из осей модели каталога (`axes`), универсально по модели (правила рендера осей сверены со справкой @pifiya §4.2):

- Порядок приоритета на тулбаре: `duration` → `voice` → `response_format`/`output_format` → `language` → прочие `select`-оси. Максимум **4 чипа** в ряду, остальные — в шите параметров (паттерн `MediaParamSheet`).
- `select` с ≤ 6 опциями — чип-строка; `select` с большим списком (голоса 9–30) — чип с текущим значением, открывающий шит выбора. `toggle` — чип-переключатель (активный = `primaryContainer`). Короткие `text` (`bpm`, `speed`) — инлайн-поле в шите; длинные (`lyrics`, `style`, `instructions`, `script`) — многострочное поле в раскрытии шита.
- Технические оси (`seed`, `sample_rate`, `bitrate`, `channel`, `stability`, `similarity_boost`) — только в «Ещё», на тулбар никогда.
- Вид чипа — существующий `TopBarChip`; текст чипа = короткое значение: «30 с», «Rachel», «MP3», «RU». Полный лейбл оси — в шите. Обязательные оси (`required`) — первыми.
- Ось `duration` показывать только если она есть у модели: у TTS цена считается за символы, и чип длительности был бы фикцией.

Цена и отправка:

- Бейдж цены в шите: `от {цена} ₽ {единица}` — строка `unit` каталога как есть («за 1000 символов», «за трек», «за секунду», «за файл», «за озвучку»); десятичный разделитель — запятая (локаль ru). У `priceStatus=estimate` — префикс «≈» и подсказка из `priceWarning`.
- Перед отправкой — котировка `POST /api/media/price`; кнопка дока показывает итог: **«Создать · ≈ 12 ₽»**. Для тарифицируемых по входу моделей (`за 1000 символов` / `за секунду`) в `generate` уходят `quote_id` + `max_price_rub`. Если цена не изменилась при повторе — не переспрашивать.
- Если у модели есть `tiers` (цена зависит от выбранных чипов) — бейдж пересчитывается при смене чипа; нет совпадения → «от» по `fromRub`.

Шит моделей аудио (состав и дефолты — по справке @pifiya §4.1):

- Три группы с заголовками, внутри — сортировка по цене «от»: **Голос** (19 TTS), **Музыка** (5), **Эффекты** (4). Отдельный пункт «Мой голос» — модели с клонированным голосом (`voice_id` через `POST /api/media/voices`).
- Дефолты: голос — `gpt-4o-mini-tts`; музыка — `suno` (маршрут `suno:white`); эффекты — `elevenlabs-sound-effects-v2`.
- Никогда не показывать в шите генерации: STT/аналитику (вход `audio_url`), музыкальные трансформации с аудио-входом и утилиты — итого 29 моделей вне v1.
- Пометки на карточках: «только английский» (`kokoro-tts`), «до 300 символов за запрос» (`chatterbox-tts`), «уточняется по длительности» (`mirelo-sfx-2`).

## 3. Аудио-элемент на канвасе (плеер)

- Карточка того же размера 232 `.dp`, фон `surfaceVariant`, скругление `12.dp`, выделение — то же кольцо `2.dp primary`. Сетка канваса остаётся однородной.
- Наполнение карточки: волновая дорожка по всей ширине (пики `onSurfaceVariant` 40 %, проигранная часть — `primary`), по центру круглая кнопка воспроизведения `52.dp` `primaryContainer` (форма кнопки «Создать» в доке), снизу время `0:12 / 0:30` (`labelSmall`, как в видеоплеере).
- Воспроизведение — внутри приложения (без системного плеера): `expect/actual` по образцу `PlatformVideoView` (десктоп — media3/JavaSound, Android — MediaPlayer).
- Управление:
  - **Перемотка:** клик/драг по волне = переход к позиции; тонкий `Slider` под волной — всегда при выделении. Тач-цель скраббера ≥ 44 `.dp` независимо от толщины линии (важно для KMP-тача на десктопе/планшете).
  - **±10 с:** кнопки `rewind.svg` / `forward.svg` в панели выделенного элемента.
  - **Скорость:** пресеты `0.5× / 0.75× / 1× / 1.25× / 1.5× / 2×` чипами (активный — `primaryContainer`); в карточке — только в панели выделения, полный набор — в редакторе.
  - **Громкость:** иконка `volume.svg` + горизонтальный `Slider` 0–100 %; клик по иконке = mute (иконка приглушается до 40 % альфы).
- Панель выделенного аудио-элемента (те же `ElementChip`): воспроизведение/пауза, «Редактировать» (§4), «Прикрепить к видео» (§6.4), «В таймлайн» (§7), `SaveAlt` «Сохранить в галерею», `Delete`. Операция «Использовать как референс» для аудио не показывается.
- Скелетон генерации аудио = существующий `GenerationSkeleton` (без изменений).

## 4. Редактор аудио

Вход: чип «Редактировать» в панели выделенного аудио-элемента. Полноэкранный шит (по образцу лайтбокса): шапка (название, длительность), волна на всю ширину, управление снизу.

- **Волна:** зум (Ctrl+колесо / пинч), плейхед, линейка времени (шаг 5/10 с в зависимости от зума). Выделение = драг по волне; у выделения ручки по краям (как трим-хэндлы клипов в CapCut). Волна показывается потому, что по ней действуют (ищут тишину, режут ложный старт); для чистого воспроизведения без правок достаточно прогресс-бара.
- **Обрезка:** «Обрезать до выделения» (`trim.svg`) — остаётся только выделенный диапазон; отдельно «Обрезать начало/конец до плейхеда». Обрезка неразрушающая: обрезаются края клипа за ручки, скрытое можно оттянуть назад; все правки — в стек отмены (без ограничений в рамках сессии, паттерн настольных аудиоредакторов).
- **Разрезать:** плейхед + «Разрезать» = два независимых клипа (паттерн CapCut Split).
- **Скорость:** слайдер 0.25–4.0 + пресеты 0.5/1/1.5/2; тумблер **«Сохранять тон»** (вкл. по умолчанию — для речи, чтобы не было «бурундука»). Изменение скорости — предпрослушивание без переписывания файла; в файл рендерится только при экспорте.
- **Склейка 2+ треков:** кнопка «Добавить трек» (`+`) — выбор из аудио-элементов канваса, журнала или файла. Треки — вертикальный список строк со своей волной, тримом и громкостью; порядок = перетаскивание; склейка = последовательное соединение сверху вниз (без микширования — микс выйдет в следующих версиях). Кнопка «Предпросмотр склейки» проигрывает результат.
- **Сравнение с оригиналом:** в шапке редактора переключатель «Оригинал / Результат» (A/B) — обработанное всегда слышно рядом с исходным.
- **Экспорт:** «Экспорт» → чипы формата (MP3 / WAV), затем «Сохранить в галерею» и/или «Добавить на канвас как новый элемент». Рендер локальный, с `LinearProgressIndicator`. Фейды (вход/выход) — не в v1; когда появятся, у каждого своя длительность с явным нулём («0 = выключено»), без скрытых дефолтов.
- Закрытие с несохранёнными правками — подтверждение: «Сохранить изменения?» → «Сохранить» / «Не сохранять» / «Отмена».

## 5. Рисование карандашом на изображении

Вход: чип «Карандаш» (`brush.svg`) в панели выделенного изображения.

- Полноэкранный режим: изображение на весь экран; внизу — стеклянная капсула инструментов (как верхняя капсула тулбара):
  - **Кисть:** в v1 одна кисть с тремя пресетами толщины (тонкая 2, средняя 6, толстая 14 `.px`) — иконка `line-weight.svg`.
  - **Цвет:** 8 свотчей (чёрный, белый, красный, оранжевый, жёлтый, зелёный, синий, фиолетовый) + индикатор текущего. Кастомный цветовой круг — не в v1.
  - **Толщина:** слайдер 1–32 `.px` с круглым превью на ползунке.
  - **Отмена:** `undo.svg` — отмена по штрихам (стек); «Очистить всё» — с подтверждением.
  - **Отмена режима:** крестик — сбрасывает штрихи (подтверждение, если штрихи есть).
  - **Применение:** `apply.svg` — штрихи запекаются в **копию**; оригинал генерации не трогается; копия появляется на канвасе рядом и связана с исходной задачей (недеструктивный паттерн).
- Штрихи хранятся векторно (путь, цвет, толщина) и рисуются `Canvas` поверх изображения со сглаживанием (квадратичные кривые по точкам).
- Десктоп: ЛКМ — рисовать, `Ctrl+Z` — отмена; тач/стилус поддерживаются тем же жестом.

## 6. Операции редактирования изображений/видео на канвасе

Каждая операция открывается полноэкранно с предпросмотром и парой «Применить» / «Отмена». Исходник никогда не перезаписывается: результат — новый элемент, связанный с исходной задачей.

- **Обрезка** (`crop.svg`): рамка с ручками, сетка третей; чипы соотношения: Свободно · 1:1 · 4:3 · 3:4 · 16:9 · 9:16. Для видео — та же рамка (кадрирование кадра, не времени; время режется в таймлайне §7).
- **Размер** (`resize.svg`): существующие жесты масштаба + шит: поля «Ширина/Высота» в `.px`, тумблер «Сохранять пропорции» (вкл. по умолчанию), пресеты 512 / 1024 / 2K. Определяет разрешение экспорта элемента.
- **Наложение** (`overlay.svg`): перетащи элемент B на элемент A → чип «Наложить»: B становится дочерним слоем A — позиция и масштаб считаются от рамки A, двигается вместе с A; `zIndex` внутри родителя; «Открепить» возвращает самостоятельность. В панели наложения — слайдер прозрачности 0–100 % (по умолчанию 100 %).
- **Аудиодорожка на видео** (`audio-track.svg`): чип «Музыка» в панели выделенного видео → выбор: аудио-элементы канваса, журнал (`kind=audio|music`), импорт файла. Прикреплённая дорожка отображается волновой полосой `24.dp` под элементом; доступны громкость, «Заменить», «Убрать». Дорожка следует за клипом при сборке в таймлайн (§7).

## 7. Таймлайн — сборка видео из элементов канваса

Вход: пятая кнопка верхней капсулы тулбара — `timeline.svg`, подпись-подсказка «Собрать видео». Открывает нижний ящик: сверху предпросмотр текущего кадра, снизу лента (компоновка CapCut: **плейхед зафиксирован по центру, лента прокручивается под ним** — так удобнее и мышью, и пальцем).

- **Добавление:** чип «В таймлайн» (`add-clip.svg`) в панели выделения любого элемента; плюс `+` в конце ленты — выбор из канваса/журнала (паттерн CapCut/VN).
- **Клипы:** изображение = стоп-кадр с чипом длительности (по умолчанию 3 с; меняется перетаскиванием правого края); видео = полоса миниатюр с реальной длительностью; аудио = волновая полоса в нижней дорожке.
- **Дорожки в v1:** одна главная видеодорожка + одна аудиодорожка. Мультитрек — будущая версия (простота прежде всего).
- **Операции на ленте:** перестановка перетаскиванием; трим за края (у видео — покадровый при зуме); удаление; клик по стыку клипов = слот перехода: «Нет» (жёсткая склейка, по умолчанию — правильный дефолт) или «Затемнение» 0.3/0.5 с. Больше переходов не нужно: частые эффекты удешевляют монтаж.
- **Плейхед:** скраббинг = перетаскивание ленты; зум масштаба времени — Ctrl+колесо (десктоп) / пинч (тач); предпросмотр всегда синхронен с плейхедом.
- **Аудиодорожка:** треки выкладываются последовательно, двигаются перетаскиванием; громкость — слайдер на выбранном треке. Автоподгонка не нужна — точность даёт зум.
- **Экспорт:** «Экспорт видео» → шит: разрешение 720/1080, fps 24/30, ориентировочный размер; рендер с `LinearProgressIndicator` и кнопкой «Свернуть» (работа со студией продолжается, в верхней капсуле появляется бейдж «Сборка видео…», клик — вернуться к прогрессу). Результат — новый видео-элемент на канвасе + запись в журнале.

## 8. Состояния ошибок

Единый паттерн для любой неудачи (генерация, скачивание, экспорт, импорт). Состав (по канону AI error states):

1. **Суть** — что случилось, одним человеческим предложением; без кодов и трассировок.
2. **Причина** — категория: сеть / провайдер / лимиты / фильтр контента / параметры / файл.
3. **Спасение** — 1–3 кнопки: основная «Повторить», вторая — целевое действие, третья — «Скрыть/Отмена».
4. **Сохранённый ввод** — промпт, параметры и референсы никогда не очищаются ошибкой.

Размещение:

- На канвасе вместо скелетона — карточка ошибки: фон `errorContainer`, иконка `error.svg`, заголовок + текст + кнопки.
- В журнале неудачная запись получает бейдж ошибки и кнопку «Повторить».
- Мелкие сбои (галерея, буфер обмена) — `Snackbar` с действием, без карточек.

Типовые сбои (заголовок → текст → действия):

| Ситуация | Заголовок | Текст | Действия |
|---|---|---|---|
| Сеть | Нет связи | Не удалось связаться с сервером генерации. Проверьте интернет и повторите. | Повторить · Скрыть |
| Таймаут | Сервис не ответил | Сервер не ответил вовремя. Обычно помогает повтор через минуту. | Повторить · Другая модель |
| Очередь провайдера | Сервис перегружен | Очередь провайдера переполнена, генерация не началась. | Повторить позже · Другая модель |
| Баланс | Недостаточно средств | Для этой генерации не хватает {цена ₽}. | Пополнить · Модель дешевле |
| Фильтр контента | Запрос отклонён | Фильтр безопасности отклонил запрос или исходное изображение. Измените описание и повторите. | Изменить промпт (фокус в док) |
| Параметры | Параметры не подходят | Выбранное сочетание параметров недоступно для этой модели. | Сбросить параметры |
| Скачивание | Файл не скачался | Результат не удалось сохранить локально. Ссылка живёт 5 дней — попробуйте ещё раз. | Повторить скачивание |
| Экспорт аудио | Не удалось собрать аудио | Файл не сохранился. Проверьте свободное место и повторите. | Повторить экспорт |
| Рендер видео | Не удалось собрать видео | Рендер остановлен: {причина}. Проект таймлайна сохранён. | Повторить · Уменьшить разрешение |

Правила: «Повторить» всегда отправляет **тот же ключ идемпотентности** (двойного списания нет); котировка цены показывается заново только если параметры менялись; у ошибок генерации в карточке сохраняется миниатюра промпта — видно, что именно не удалось.

## 10. Что исследовано (источники решений)

- **CapCut** — контекстный тулбар по выделению; зафиксированный плейхед с лентой под ним; переходы кликом по стыку клипов; трим за края; скорость обычная/кривая; бит-маркеры на волне; темплейт-поток рядом с ручным таймлайном.
- **VN** — мультитрек (видео/аудио/оверлеи), магнитная лента, режимы Quick/Pro, аудиодорожка над видео, точный трим с зумом, синхронизация по пикам волны.
- **Canva Magic Studio** — выбор стиля миниатюрами вместо лексикона промптов; точка входа на генерацию прямо в потоке подбора контента; опция «без стиля» по результатам тестов; рост вовлечённости после интеграции в контекст редактора.
- **WavePad / Lexis / AudioCraft** — волна + выделение + зум как основа аудиоредактора; трим тишины; неограниченная отмена; пресеты скорости 0.5–2×.
- **Picsart / Snap Markup / Apple Markup** — рисование-аннотация: кисть, свотчи цвета, отмена по штрихам, применение к копии.
- **Runway / Midjourney + UX Patterns «AI Error States»** — структура ошибки: суть → причина → спасение → сохранённый ввод; восстановление должно соответствовать реальному типу сбоя.
- **Справка @pifiya** (`/home/al/wiki/design/pots-audio-gen-research.md`) — состав шита аудио-моделей, правила чипов по осям, цена/единицы, лучшие практики аудиоредакторов (волна только когда по ней действуют, неразрушающий трим за ручки, предпрослушивание скорости без переписывания файла, A/B с оригиналом, фейды с явным нулём, тач-цель скраббера ≥ 44 pt).
- **Material 3** — роли цветов `errorContainer`/`error`, снейкбары с действием, иконки 24 `.dp`/18 `.dp`.
